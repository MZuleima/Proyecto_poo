# Casos de Uso Principales

1. **Registrar Incidencia**: El técnico detecta un fallo, lo describe y queda registrado con la hora actual.
2. **Traspasar Turno**: Si una incidencia queda "Pendiente", el sistema permite enviar un aviso al técnico que entra en el siguiente turno.
3. **Cerrar Incidencia**: Se introduce la solución y el sistema cambia el estado automáticamente a "Solventada".
