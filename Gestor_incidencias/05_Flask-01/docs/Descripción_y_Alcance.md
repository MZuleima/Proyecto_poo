# Descripción y Alcance del Proyecto

## Propósito
El sistema "Gestor de Incidencias Técnicas" nace para digitalizar el control de fallos en salas de control críticas. Su objetivo es asegurar que ningún problema quede sin resolver al cambiar de turno.

## Alcance
- **Gestión de Activos**: Control de salas (ubicación) y técnicos (turnos).
- **Ciclo de Vida**: Registro de apertura, seguimiento y cierre formal de incidencias.
- **Comunicación**: Sistema de avisos internos para el relevo de técnicos.
- **Documentación**: Generación de informes en formato borrador (pendientes) o acta final (solventadas).
